# DSA-Analysis-Design

This project is oriented around building a suitable data structure to use in a course catalog system. The courses are parsed from line by line from a CSV file and inserted into a data structure. This menu is intended to support the functions of printing a sorted list, uploading courses from a file, and searching for a particular course. Through some analysis of data structures, the main approach was to deliberate and decided what would be a fitting data structure to use for the project. While data structures are not without pros and cons, it is about finding a balanced approach. In other words, what I was willing to compromise for the overall purpose of the program. 
Ultimately, I ended up blending a hash table with an extra vector to provide a sorting function. This project certainly emphasizes the preperation and necessity of a plan before running the guantlet to develop a program. I had to some tweaks and changes to the initial idea, but these were not so slowdowns. These were more a change in direction. Although, the coded section is in a single file, the file is still segmented to provide a clearer understanding of what the code is intended for along with frequent comments on the process of the each function.
