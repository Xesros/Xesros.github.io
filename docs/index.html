Self-Assessment

Seeing Growth

The process of enhancing previous projects has shown me the growth I often overlook at a personal and professional level. I tend to struggle to perceive what progress of my skills looks like. I’ve realized that my older previous work throughout my degree while they complete the metric of technical skills such as understanding time complexities, design and planning, programming layers and languages, cybersecurity, and so on were done in a somewhat selfish fashion. This shortsightedness led me to struggle with evaluating my old work both for school and personal use. My vague descriptors of files and code, missing documents in older repositories, and lack of foresight are not healthy for collaborating in a team environment nor communicating with stakeholders.

However, I’ve learned to overcome these limitations. I’ve been taught to mirror common software development lifecycles (Agile, Scrum) and to gather requirements both technical and qualitative from research and from customers. It is always best to refer to secure coding best practices and, or a coding standard to ensure software is both functional and protected. I’ve engaged with problems that require balancing data structures and algorithms’ time complexities for performance and practicality. I have worked with various coursework projects from small programs for one goal, larger scale programs that needed me to implement automated testing where it be static or dynamic, and configured various databases for coursework, both SQL and non-relational.

It took some time to learn each of these facets of the program, but growth is growth. This could only be achieved because I continuously exposed myself to new topics and technologies. Computer Science is a broad field that requires a wide set of knowledge, skills, and expertise to create something that works.

Included Projects

The included projects have been enhanced to meet a higher standard of quality and professionalism. I improved their project structure/design, code quality, and improved their performance. The first of two projects is a full-stack single page web application. This project was originally a small python program that directly interfaced with a mongo database to host a data dashboard for an animal shelter. I’ve swapped to a more flexible and widely supported software stack known as the MEAN stack. This suite of software is comprised of MongoDB, Express, Angular, and Node.js. The change enables me to utilize a variety of components/tools to expand the functionality, try new tools, and securely/properly host the database and webpage. You may follow to more details of the software design/engineering here. This project also required some database work which you can find more details here.

The second project is on the smaller side. It is a project oriented on building a course catalog for a university. The original, while it works, is not an optimal usage of a data structure and sort algorithm. I’ve implemented a different data structure, a binary search tree, to meet the requirements established in the original version. The new data structure offers a better balance of a more consistent and preferrable time complexity compared to the previous version which utilized a hash table. You can find more details regarding this project here.
