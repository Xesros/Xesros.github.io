## Software Design & Engineering
The project that covers the concepts of Software Design & Engineering is the [Animal Shelter Dashboard](Animal_Shelter_Dashboard/Enhanced%20Dashboard/). The goal of this project is provide an animal shelter with a data dashboard to meet their business needs. The project is a conversion a small python + mongodb app into a full stack web page application. The software suite powering the single web page application is the MEAN stack. The project incorporates a flexible and better structured design to meet the goals of the project. The improved structure provides more control and reduces technical debt with its modularity. While still both dynamic typed languages, the language/software conversion meant replacing components with suitable equivalents. An important aspect of building the project is the way data is structured and managed in the application. Originally, this required some outside configuration and manually loading the data from a csv file. Now, the application builds with a defined and consistent schema. The data is loaded from a script to match.

## Data Structures & Algorithms
The project which highlights the category Data Structures and Algorithms is the [Course Catalog System](Course_Catalog/Enhanced%20Project/). The project is not as massive as a overall compared to the other project, but it does deal with important concepts. The main enhancement of the project is to change the internal data structure to a more suitable one. Suitable meaning better time complexity and application to the program. The original uses a Hash Table to hold course objects, while the newer uses a Binary Search Tree. The documents of the project discuss how the conversion is a better balance for the program as a whole.

## Databases
The project that covers Databases is the [Animal Shelter Dashboard](Animal_Shelter_Dashboard/Enhanced%20Dashboard/). The goal of the project is to provide a data dashboard to the an animal shelter. The organization needs a fluid experience and interface accessing their records of animals. The enhancement of this project, besides a more capable structure and software stack, is how the data is being managed. Originally, the data was manually uploaded and configured to a database. This database had a user account also created for the purpose of logging in and editing it. A glaring issue with this was how the project included this credentials hardcoded into the source code, so that the program could automatically link to the database. The front-end was directly querying for the data. The new project defines the structure of the data in the form of schemas, the loading of data to the database, validators to user input, builds a server to act as an in-between the front-end and database, and implements server side pagination to optimize query times.
